# Learning Change Routing

## Required field or schema

Use when a missing fact repeatedly breaks handoffs, meetings, decisions, portfolio state, or evidence traceability.

## Template

Use when people know what to do but omit a repeatable artifact section or output field.

## Validator or script

Use when a deterministic check can detect the failure before delivery.

## Automation or connector configuration

Use when the failure is a repeated transfer, synchronization, notification, or scheduling step with stable rules.

## Router condition

Use when the correct specialist workflow or safety boundary does not activate for a recognizable request.

## Skill instruction

Use when the correction requires judgment that cannot be encoded more reliably elsewhere. Keep it narrow and test it with a realistic request.

## Backlog

Use when the structural fix is valuable but outside the current scope, ownership, or authority. Record the owner and trigger for revisiting it. Do not use backlog as a place to hide rejected advice.
