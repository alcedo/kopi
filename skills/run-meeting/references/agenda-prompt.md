# Agenda Synthesis Prompt

## Inputs

- Purpose: `{purpose}`
- Decision needed: `{decision}`
- Participants and roles: `{participants}`
- Available time: `{duration}`
- Pre-read evidence: `{evidence}`
- Open risks and disagreements: `{open_items}`

## Task

Create the smallest agenda that can reach the named outcome. Allocate time to framing, evidence, option discussion, decision, and action ownership only when each is needed.

For every agenda item, state the owner, input, method, output, and minutes. Put information-only material in the pre-read. Flag any decision that cannot be made because evidence or authority is missing.
