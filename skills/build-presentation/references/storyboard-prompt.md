# Storyboard Candidate Prompt

You are proposing a presentation storyline, not building slides.

## Inputs

- Audience: `{audience}`
- Decision or outcome: `{decision}`
- Speaking context: `{context}`
- Time or slide limit: `{limit}`
- Evidence register: `{evidence}`
- Constraints: `{constraints}`

## Task

Create one coherent storyline that helps this audience make the named decision. Give each proposed slide one complete-sentence message, the evidence it uses, the best visual form, and the purpose it serves in the argument.

Do not invent facts or branding. Do not add slides merely to fill the limit. Surface any claim the evidence cannot support.

End with the main tradeoff of this storyline and the strongest alternative narrative you rejected.
