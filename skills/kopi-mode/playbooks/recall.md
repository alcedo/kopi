# Recall Playbook

Use `recall-work`.

1. Bound the topic, workspace, and time window. Do not broaden “my work” across unrelated projects.
2. Search prior conversations and handoffs for decisions, attempts, artifacts, and open threads.
3. Reconcile those historical records with live trackers, documents, calendars, repositories, and other available systems.
4. Report current workstreams, status, blockers, stale or contradictory claims, and the one best next move.
5. Keep raw history out of the final brief. Preserve source pointers so the user can verify it.

Use the prior trail to avoid rediscovery, but do not mistake prior self-report for current truth.
