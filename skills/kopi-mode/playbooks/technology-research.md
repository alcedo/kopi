# Technology Research Playbook

Use `research-technology`.

1. Fix the scope, current versions or practices, decision horizon, and as-of timestamp.
2. Browse at run time. Prefer official documentation, release notes, repositories, standards, and original research.
3. Separate shipped changes, announced plans, community interpretation, and your own inference.
4. Compare the evidence with the user's actual architecture, roadmap, constraints, and adoption cost.
5. Report claim-level sources, dates, confidence, contradictions, unavailable evidence, and a recommendation.
6. Propose experiments only when source evidence cannot settle a decision that materially affects the recommendation.

“Latest” without a fresh search is an invalid result.
