# Data Analysis Playbook

Use `analyze-data`.

1. Define the decision, population, metric, comparison, and time window.
2. Inspect source shape, provenance, missingness, duplicates, units, time zones, and selection effects.
3. Preserve a reproducible transformation path from source to result.
4. Test plausible alternative explanations and sensitivity to material assumptions.
5. Create only charts that answer the decision. Tie each claim to a metric and source.
6. Verify calculations and rendered charts. Distinguish description, correlation, causal evidence, and speculation.
7. Return the analysis artifact, findings, limitations, and recommended next action.
