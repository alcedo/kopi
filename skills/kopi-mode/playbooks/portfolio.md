# Portfolio Playbook

Use `control-portfolio`.

1. Define the portfolio boundary and reporting date.
2. Gather authoritative work, decision, risk, milestone, and meeting sources.
3. Resolve stable initiative identities, deduplicate records, and reconcile conflicting status.
4. Flag missing owners, stale updates, blocked dependencies, slipping milestones, unresolved decisions, and risks without mitigation.
5. Produce a compact intervention view backed by a detailed register and source pointers.
6. Write updates to trackers only when requested. Re-read changed records and record partial failures.

Summaries are derived views. Do not create another status store when an existing system can remain authoritative.
