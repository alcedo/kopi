# Autonomous Run

**Invoked when the user asks for work to run to completion without checking in.** It owns the exit condition and the discipline that reaches it without drift.

1. State the exit condition as something checkable before the first pass. The artifact exists and passes verification. Every register row has an owner and a date. Every open decision is closed or escalated. All named deliverables are complete. Agree it with the user when the request leaves it vague.
2. Fix the boundary for the whole run. Scope, sources, audience, and external-write authority come from the frame once and do not widen mid-run because a new lead looked interesting.
3. Work in units that each end in a check. One unit changes one artifact, gets verified, and is saved before the next begins. Do not batch verification to the end.
4. Discard what did not help. An addition kept because it might help is drift. Remove it and record that you did.
5. Handle in-run discoveries yourself while they are reversible and in scope: a missing source, a stale record, a broken template, a contradiction. Surface only an irreversible action, a genuine preference call no observation can settle, or a real dead end. Return to the exit condition after each side fix.
6. Checkpoint each pass in one line: what changed, whether the exit condition moved, what is next. Write it where a cold start can read it.
7. Stop when the exit condition is met. A plateau is not a stop, so change approach and push past it. Surface a genuine dead end instead of spinning, and never relax the exit condition to declare completion.

Reply with the exit condition, passes run, what was produced, what was discarded, and the final state of the condition.
