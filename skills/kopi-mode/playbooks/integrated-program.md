# Integrated Program Playbook

Use when several workflows are required to reach one outcome.

1. State the outcome, audience, deadline, authoritative sources, external-write boundaries, and done condition.
2. Confirm each named input is available inside the active scope. Missing inputs stay missing; do not replace them with similarly named material from another project.
3. Draw the dependency order using the shared artifact model. Research and data usually precede decisions; decisions precede meetings, tracking, and presentations.
4. Assign one owner per workstream and one source of truth per record type.
5. Run independent evidence slices in parallel. Aggregate before decisions or external writes.
6. Keep a compact checkpoint with completed artifacts, current evidence, open decisions, blocked work, and next actions.
7. Verify each real deliverable through its specialist skill before declaring the program complete.

Do not add program ceremony when one specialist workflow can finish the request.
