# Status Capsule Contract

## Capsule

At most five bullets. State what the work is, where it stands overall, the latest material change, the main blocker or decision, and the next milestone only when each is supported.

## Workstreams

One line per active workstream. Use exactly one status:

- `[done]`
- `[in progress]`
- `[blocked]`
- `[at risk]`
- `[planned]`
- `[paused]`
- `[cancelled]`
- `[superseded]`
- `[unknown]`

Include owner, latest evidence date, next action, and source pointer. Do not mark work done from a plan or self-report alone.

## Problems

At most five recurring or decision-relevant problems. Include failed or reversed approaches so the next attempt does not repeat them.

## Gaps

Name unavailable sources, contradictory state, unresolved identities, and stale records.

## Next move

Give one concrete action that best advances or clarifies the work. Do not end with a menu unless a genuine product choice remains.
